# 收件箱 使用说明

## 谁该用

- 手上事情多、想一句话记下来的人
- 要把事派给同事、看谁手上最多的负责人
- 会后要把会议待办、别处的清单搬进来统一跟进的人

## 三步上手

1. **记**：在输入框写一句话，比如「明天下午三点前把合同发给张三，重要」，确认后保存
2. **看**：「今天」看到期和逾期的事，「本周」看周报，「全部」看所有没做完的
3. **整理**：事情多了点右上角「选择」，或手机上长按一条，一次改期、指派、完成、归档

## 批量整理怎么用

- **进入多选**：点右上角「选择」，手机上长按一条
- **选中**：点行就是选中，这时不会打开，也不会标完成。右上角「全选」展开两项：「全选本屏」选当前列出来的；「全部选中」选这个视图里的全部，超过 200 条也算，一次最多处理 1000 条
- **操作**：底部操作条有改期（今天 / 明天 / 下周一 / 自定义）、指派、完成，归档在「更多」里
- **撤销**：操作后提示「已处理 N 条」，3 秒内点「撤销」或按 `z` 还原
- **跳过的情况**：别人派给你的事，你只能标完成。选中了这种事去改期、指派、归档时，提示会写明跳过了几条，其余照常处理
- **归档**：不是真的删，到「已完成」底部的「查看已归档的事」里可以恢复。归档后不进列表、统计和推送

键盘（桌面）：

| 按键 | 作用 |
|---|---|
| `j` / `k` | 下一条 / 上一条 |
| `x` | 选中当前这条 |
| `Enter` | 打开当前这条 |
| `e` | 改期（选中的，没选就是当前这条） |
| `z` | 撤销刚才的批量操作 |
| `Esc` | 退出多选 |
| `?` | 跳到「设置 → 使用说明」 |

## 导入格式

点「导入」，粘贴或上传后先进预览。逐行能改、能删、能勾选，点「导入 N 条」才入库。

| 来源 | 要求 | 说明 |
|---|---|---|
| 粘贴文字 | 多行，不超过 2MB | 一行一条，以 `-`、`*`、`1.` 开头也认 |
| 会议待办 | 从会议复制来直接粘 | `整理客户名单 @郑国栋 11-02`，前面带 `[ ]` 也认 |
| 文本 `.txt` `.md` | 不超过 2MB | 一行一条，`.md` 的标题行跳过。UTF-8、GBK 都可以 |
| 表格 `.csv` | 不超过 2MB | 有「事项 / 负责人 / 截止」表头时按列取，没有表头时逗号和换行都是分隔 |
| 图片、PDF | 暂不支持 | 请把文字复制出来粘贴 |

- 每行最多 200 字，超出的标题截断并提示，完整原文放进备注。一次最多 500 条
- 行尾能认的日期：`2026-11-02`、`2026/11/02`、`11-02`、`11/2`、`11月2日`、今天、明天、周三。只写月日时取离今天最近的那一年
- **`@` 后的名字**：对上唯一一个人就指派给他；对不上时保留名字、指派留空，预览上提示没匹配到人，列表上显示「指派 某某（待确认）」，之后指派给人，这个标记自动消失；同名时列出候选让你点
- **重复**：同标题、同日期算重复（和收件箱里已有的比，也和这次粘贴的前面几行比），灰显并默认不勾。你勾上就会导入
- 原文已勾完成的（`[x]`）默认不勾

## 去重规则

只有 AI / 快捷入口会去重（60 秒内同标题、同指派、同日期）；你在表单里手动添加的每一条都会保留

导入不走这条规则：重复项只是灰显，勾不勾由你决定。

## 周报

「本周」视图顶部是周报，底部仍是本周到期的列表。周一 0 点到周日 24 点算一周。

| 数字 | 怎么算 |
|---|---|
| 新增 | 本周创建的 |
| 完成 | 本周标完成的，不管哪周建的；重新打开的不算 |
| 完成率 | 完成 ÷（完成 + 截止在本周内还没做完的）。没事可算时显示 — |
| 逾期 | 没做完、截止日早于今天的全部，今天到期的不算 |
| 按人分布 | 没做完的事归到负责人：有指派归被指派人，否则归创建人 |
| 连续 3 天没动 | 没做完、72 小时内没有改动的 |

统计范围是你看得到的事：你创建的和指派给你的，不是全公司。归档的不算。

「复制为文本」得到一段 Markdown，可以直接发群。

## 常见问题

**改了设置要重启吗？**
不用，下一次操作就生效。设置只影响你自己。

**设置里的摘要时间不生效？**
定时推送要管理员打开（`INBOX_DIGEST=1`）。没打开时设置页会写明。

**「指派时 @ 到人」关掉会怎样？**
事情照样派过去，对方列表里能看到，只是不发平台通知。

**批量指派时对方什么时候收到通知？**
撤销时间过后才发，每人一条，写明几件事。撤销了就不发。

**没想起来撤销，3 秒过了怎么办？**
改期、指派直接再改回来；完成的到「已完成」里重新打开；归档的到「已归档」里恢复。

**AI 不可用还能记吗？**
能。整句当标题进确认弹层，保存不受影响。导入不用 AI。
